## 👨‍💻 About Me

I'm a **Backend Engineer with 3.5+ years of experience** designing, building and shipping production-grade services in **Java and Spring Boot**. I care about clean APIs, well-modelled data, automated delivery pipelines and systems that stay reliable under load.

- 🔧 Building **RESTful microservices** with Java and Spring Boot
- 🗄️ Designing and tuning **SQL** schemas, queries and indexes
- 🐳 Containerizing and deploying with **Docker** and **Kubernetes**
- 🚀 Automating build, test and release with **CI/CD** pipelines
- 🧪 Writing testable, maintainable code with a focus on quality
- 🏆 Competitive programming and problem solving keep my fundamentals sharp
